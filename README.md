# HistoryGuard（Chrome 扩展）

一个基于 Chrome Manifest V3 的本地历史记录过滤扩展，使用原生 JavaScript、HTML 与 CSS 实现，无任何第三方运行时依赖。

## 安装方法

1. 打开 Chrome 浏览器，访问 `chrome://extensions/`。
2. 打开右上角 **开发者模式**。
3. 点击 **加载已解压的扩展程序**，选择本项目根目录（包含 `manifest.json` 的文件夹）。

## 功能与规则语法

- 扩展默认开启总开关，规则列表初始为空。
- **立即清理（可选）**：在“设置”页勾选“添加规则后立即删除匹配的历史记录”后（默认开启），添加新规则时会立即扫描现有浏览器历史记录并删除匹配条目；取消勾选则仅对后续新访问生效。
- **持续过滤**：在总开关与对应规则启用时，新访问匹配网址后会自动将其从历史记录中清除。
- **三页结构**：弹窗分为“规则管理”、“清理统计”和“设置”三页，支持按规则统计清理次数，并在设置页集中管理立即清理选项、当前网页快捷添加显示/默认格式、规则批量操作（全部启用、全部暂停、清空）与 JSON 导入/导出。
### 规则示例

- 匹配 HTTP 与 HTTPS 下的指定域名及所有路径：`*://example.com/*`
- 匹配主域名及所有子域名（如 `example.com`、`sub.example.com`）：`*://*.example.com/*`
- 仅匹配 HTTPS 下的特定路径前缀：`https://example.com/private/*`
- 保留显式端口（如本地开发服务）：`*://localhost:3000/*`
- 匹配任意域名下的特定路径：`*://*/secret/*`

### 规则说明

- 协议仅支持 `http://`、`https://` 和 `*://`（同时匹配 HTTP 与 HTTPS）。
- 域名支持精确域名、`*.example.com` 和 `*`；`*.example.com` 同时匹配主域名与子域名，不匹配相似但不同的域名（如 `badexample.com`）。
- 路径及查询参数部分仅 `*` 作为通配符，其他正则特殊字符按字面量处理；不支持任意正则表达式。
- 新增与编辑会自动规范化协议与域名大小写，并阻止重复规则。
- 从当前网页添加默认生成 `*://当前主机/*`（保留显式端口），不支持 `chrome://`、扩展页等非 HTTP(S) 页面。

## 统计口径

- **清理次数**：按触发规则且 `chrome.history.deleteUrl` 成功返回的操作次数统计（包含新增规则时的立即清理与后续访问时的自动清理）。
- **规则明细**：每条规则独立记录今日清理次数、累计清理次数与最近清理时间；跨日后“今日清理”自动归零。
- 删除失败不会计入成功次数，并会在弹窗中显示错误提示。
- 多条规则匹配同一访问时，仅执行一次删除，统计归属列表中第一条启用且匹配的规则。
- 删除单条规则会移除该规则明细计数，但保留全局累计统计；重置统计不会删除规则。
- 规则与计数保存在 `chrome.storage.local`，浏览器重启后保留。扩展不保存被清理 URL、页面标题或访问日志，不联网、不使用云同步。

## 权限说明

- `history`：扫描历史记录、监听 `chrome.history.onVisited` 并在匹配时调用 `chrome.history.deleteUrl`。
- `storage`：在 `chrome.storage.local` 中本地保存规则与统计计数。
- `activeTab`：打开弹窗时读取当前活动标签页的网址，用于“添加当前网站”快捷生成规则。
- 不申请任何 `<all_urls>` 或全站内容读取权限。

## 手动验收步骤（Chrome 浏览器）

1. 按上方安装步骤在 `chrome://extensions/` 加载扩展，确认扩展名为 **HistoryGuard** 且显示线条风盾牌图标，无报错。
2. 先访问一个测试网页使其进入历史记录，再点击扩展图标，确认“当前网页快捷添加”自动填入对应规则，点击 **添加当前网站**，确认提示已立即清理匹配历史且 `chrome://history/` 中该记录已删除。
3. 切换到 `chrome://extensions/` 标签页再打开扩展弹窗，确认快捷添加输入框与按钮被禁用，并显示不支持原因。
4. 在“清理统计”页查看全局概览与各规则清理明细（今日清理、累计清理、最近清理时间）。
5. 再次访问匹配规则的网址，确认历史记录未保留且对应规则与全局统计均增加 `1`；访问不匹配规则的网址，确认历史记录正常保留且统计不增加。
6. 暂停该规则或关闭总开关后再次访问该网址，确认历史记录正常保留。
7. 重启浏览器后再次打开扩展弹窗，确认规则与统计数据依然保留。
